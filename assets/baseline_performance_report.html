NPSS vs pyCycle: baseline turbojet — timing & robustness

Single-spool turbojet, sea-level static. Generated 2026-06-07. pyCycle 4.4.1-dev+ee7e161, NPSS_3.2.

Key findings

  • The NPSS-vs-pyCycle equilibrium speedup depends on which NPSS package you use. vs NPSS-allFuel (CEA accuracy, fast implementation): ~256x faster per solve than pyCycle-CEA. vs NPSS-CEA (slow package): only ~1.4x. The right equilibrium comparison is pyCycle-CEA vs NPSS-allFuel.
  • allFuel = CEA-accuracy at GasTbl-speed (~178x faster than NPSS-CEA per solve). Package choice within NPSS (~178x spread) matters more than NPSS-vs-pyCycle for equilibrium thermo.
  • Off-design timing persists. On a 12-point throttle line: NPSS-allFuel ~599–2527x faster than pyCycle-CEA per point.
  • Robustness is high across the board — expected for this simple single-spool turbojet model. The one exception: pyCycle-CEA failed at one envelope corner (alt 25,000 ft, MN 0.8).

Methods (brief)

An identical single-spool turbojet (FlightConditions → Inlet → Compressor → Burner → Turbine → C-D Nozzle, single shaft; PR = 13.5, ηc = 0.83, ηt = 0.86, T4 = 2370 degR, Fn = 11,800 lbf SLS) was built in both codes. Six (tool, package) configurations were evaluated: pyCycle in CEA and TABULAR; NPSS in GasTbl, Janaf, CEA, and allFuel. Design sweeps (T4, OPR) are cross-tool rubber-engine; throttle and envelope sweeps engage component maps and are within-tool only (NPSS uses CFM56-derived maps, pyCycle uses AXI5/LPT2269). Timing uses a rigorous solve-only benchmark: cold-reset repeats, single-core pinning, median/min estimators.

Timing performance

The headline: the NPSS-vs-pyCycle equilibrium speedup is not one number — it depends entirely on which NPSS package pyCycle-CEA is compared against. Against NPSS-allFuel (same equilibrium accuracy as CEA): ~256x faster per solve. Against NPSS-CEA: only ~1.4x (NPSS-CEA is anomalously slow). Within NPSS, the per-iteration thermo cost spans ~178x: allFuel = CEA-accuracy at GasTbl-speed.

Robustness summary

Overall robustness is high across all configurations — as expected for this simple single-spool turbojet model. The cycle is low-complexity (no bleeds, no cooling, single shaft), so convergence is straightforward. The one exception is the envelope edge where pyCycle-CEA's equilibrium solver struggled.
